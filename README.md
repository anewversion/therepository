# therepository

A public “field notes from building” repo: three flagship builds I’m sharing openly so others can learn from them, use them, and (ideally) reach out if you want to build together.

Open-source here is **not** “this isn’t valuable.” It’s the opposite: it’s a factual, working proof of what I can build — shared with a pay-it-forward mindset.

## What’s inside (3 projects)

1) **Combauto** — advanced Coinbase cryptocurrency trading automation  
   *Statistical + ML hybrid scoring, custom CSD signal work, star-rated trade selection, and a production-style run loop.*

2) **Local Agent Teammate** — a multi-model automation agent that operates in a local environment  
   *Tool routing, file operations, workflows, and a “teammate” philosophy (not a magic button).*

3) **Web Data Collection + Enhancement** — business discovery, enrichment, and contact-extraction patterns  
   *Focused on real-world data work: provenance, verification mindset, and practical pipelines.*
